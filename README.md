# Machine-Learning-Practicals
Machine Learning lab practicals implemented in Python using Scikit-Learn, featuring K-Nearest Neighbors (KNN) Classification and Decision Tree Regression with hyperparameter tuning.
# Machine Learning Lab Practicals

This repository contains Jupyter Notebooks for core Supervised Machine Learning algorithms implemented in Python using `scikit-learn`, `pandas`, `numpy`, and `matplotlib`/`seaborn`.

## 📂 Repository Contents

| # | Practical | Algorithm | Key Concepts Covered |
| :--- | :--- | :--- | :--- |
| 1 | `01_KNN_Classification.ipynb` | **K-Nearest Neighbors (KNN)** | Feature scaling (`StandardScaler`), train-test split, Confusion Matrix, Classification Report, and finding optimal $K$ using the **Elbow Method** (Error Rate vs. $K$). |
| 2 | `02_Decision_Tree_Regression.ipynb` | **Decision Tree Regressor** | Regression modeling on synthetic/non-linear data, hyperparameter tuning via `GridSearchCV` (`max_depth`, `min_samples_split`, `max_features`), and model evaluation ($R^2$, MAE, MSE, RMSE). |

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python 3
* **Data Manipulation:** Pandas, NumPy
* **Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-Learn (`KNeighborsClassifier`, `DecisionTreeRegressor`, `StandardScaler`, `GridSearchCV`)
